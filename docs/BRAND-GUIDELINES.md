# CV Studio AI — Brand Guidelines (extrait Design System)

Source complète : [`DESIGN-SYSTEM-CV-STUDIO-AI.md`](./DESIGN-SYSTEM-CV-STUDIO-AI.md)

## Logo

- Wordmark « CV Studio » + « AI »
- Clear space ≥ hauteur du C
- Min height UI : 24px

| Accent    | `#EC4899` |

| Error     | `#EF4444` |

## Typographie

- **Inter** — UI & marketing
- **JetBrains Mono** — code uniquement

## Tagline

> Des CV qui passent les filtres.

## Do

- Preview CV toujours visible dans l’éditeur
- CTA primary unique par vue
- Contrastes AA+ / dark AAA

## Don’t

- Bouton « Prévisualiser »
- Glow / confettis dans l’éditeur
- Hardcoder les couleurs hors tokens
