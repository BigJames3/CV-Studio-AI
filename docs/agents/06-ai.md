# 06 — AI

## Mission

Rendre les fonctionnalités AI réelles, bornées par les quotas, l'historique, et les entitlements. Une route HTTP 200 avec un score fixe n'est pas une feature AI terminée.

## Responsabilités

- `packages/ai-service` : providers, prompts, routing, fallback
- `apps/api/src/modules/ai` : contrôleur, service, quotas, rétention
- Classer chaque feature : REAL, PARTIAL, HEURISTIC, SCAFFOLD, MOCK, NOT_IMPLEMENTED
- Ne pas brancher un modèle sur un endpoint scaffold sans quota, entitlement, historique, et test

## Security rules

- Vérifier que le `cvId` appartient à `userId` avant tout traitement (déjà fait sur plusieurs méthodes ; le garder sur toute nouvelle feature).
- Ne pas logger le texte intégral du CV.
- Le fallback heuristique ne doit pas être présenté au client comme un modèle nommé OpenAI si `provider` vaut `heuristic`. Le cover-letter retourne aujourd'hui un nom de modèle « openai » possible alors que le provider est heuristique (`gateway.ts` `runCoverLetter`) : ne pas empirer cette ambiguïté.
- Quotas : le check-then-insert actuel est une course (API-002). Un correctif de quota dans ce module est autorisé ; un changement des chiffres 0/50/200 est une décision produit.

## Testing rules

`jest.config.json` échoue le coverage si `ai.service.ts` ou `ai-quota.service.ts` descendent sous le seuil. Lancer :

```bash
pnpm --filter @cvstudio/api exec jest --config jest.config.json src/modules/ai/ai.service.spec.ts
pnpm --filter @cvstudio/api exec jest --config jest.config.json src/modules/ai/ai-quota.service.spec.ts
```

Un test qui assert `matchScore === 68` documente le mock. Le remplacer par un oracle réel seulement quand l'implémentation cesse d'être un mock.

## Workflow

```text
Lire gateway.ts et la méthode du service
→ classer REAL / HEURISTIC / SCAFFOLD / MOCK
→ si la tâche est « rendre réel » : quota, entitlement, history, coût si la colonne existe, test
→ ne pas laisser un faux jobId « queued » sans worker
```

## Definition of Done

- La classe de la feature est honnête dans la réponse (`provider` réel)
- Entitlement + quota si la feature consomme du modèle ou un budget
- Historique écrit dans la même unité que le quota (aujourd'hui ce n'est pas transactionnel)
- Tests ciblés verts
- Pas de clé dans le diff

## Carte AI vérifiée

| Endpoint                        | Classe            | Détail                                                                                                                 |
| ------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `POST ai/optimize-resume`       | REAL ou HEURISTIC | `optimizeResumeWithOpenAi` si `AI_PROVIDER=openai` ou clé ; sinon heuristique ; fallback heuristique si l'appel échoue |
| `POST ai/generate-cover-letter` | HEURISTIC         | Commentaire gateway : chemin OpenAI « later ». Quota oui. Historique oui                                               |
| `POST ai/check-ats`             | PARTIAL           | Score local par mots-clés. Explain heuristique. Persiste `AtsReport` + `AiHistory` (`actionType: jd_match`)            |
| `POST ai/explain-ats-score`     | PARTIAL           | Délègue à `checkAts`                                                                                                   |
| `POST ai/generate-cv`           | SCAFFOLD          | `queued()` faux `jobId`                                                                                                |
| `POST ai/match-job`             | MOCK              | `matchScore: 68` et texte « scaffold »                                                                                 |
| `POST ai/interview-prep`        | MOCK              | Question statique                                                                                                      |
| `POST ai/career-advice`         | MOCK              | Carte statique                                                                                                         |
| `POST ai/generate-portfolio`    | SCAFFOLD          | `queued('portfolio')`                                                                                                  |
| `POST ai/grammar-check`         | SCAFFOLD          | Renvoie le texte tel quel                                                                                              |
| `POST ai/skills-suggest`        | SCAFFOLD          | `suggestions: []`                                                                                                      |
| `POST ai/linkedin-import`       | SCAFFOLD          | Faux `jobId`                                                                                                           |
| `POST ai/parse-pdf`             | SCAFFOLD          | Faux `jobId`                                                                                                           |

Quota journalier (`ai-quota.service.ts`) : optimize 0/50/200, cover 0/20/100, ats-explain 1/20/100 (free/pro/business). Pas de quota interview. `cost` du modèle Prisma n'est pas écrit (seulement `tokensUsed`). Rétention : cron `ai-retention.job.ts`.

`runAiFeature` default : `AI feature not wired yet`.
