# Disputes & copyright — Marketplace

## Buyer disputes (≤ 14 days)

1. Open from purchase receipt / PDP
2. Types: quality · access · billing
3. Seller has 48h to respond
4. Platform decides in ≤ 5 business days
5. Outcomes: full/partial refund, deny, provide fixed version

## Copyright claims

1. Submit notice with work ID, proof, contact
2. Listing suspended within 24h if credible
3. Seller may file counter-notice (jurisdiction-dependent)
4. Repeat infringers terminated; payouts held
